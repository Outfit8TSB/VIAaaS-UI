experimental Velocity plugin that makes VIAaaS Easier to use.

# Setting up
Spin Up Your Velocity Proxy and put the plugin. No Config Required!

# Connecting:
It's Really Similar to the ViaProxyConnect. In Fact, it's a VIAaaS+Velocity Version of ViaProxyConnect.

To Connect, type `/viaconnect address[:port] -u [username] -v [version]`
## Examples:
* /viaconnect 2b2t.org
* /viaconnect 2b2t.org:25565
* /viaconnect 2b2t.org:25565 -v 1.8
* /viaconnect 2b2t.org:25565 -ucreeper123123321 -v 1.8
